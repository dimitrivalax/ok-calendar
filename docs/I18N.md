# Internationalisation (i18n)

**Objectif.** Définir la stack et les règles EN/FR. Voir [ADR-0009](adr/0009-i18n-fr-en.md), [SPECS.md](SPECS.md) §12.

## Décision

| | |
|--|--|
| Stack | `i18next` + `react-i18next` + `expo-localization` |
| Défaut | **`en`** |
| Fallback | **`en`** |
| Locale complète additionnelle | **`fr`** |

## Fichiers

```
src/i18n/
  index.ts
  locales/
    en/common.json
    en/calendar.json
    en/event.json
    en/settings.json
    en/notifications.json
    fr/common.json
    fr/calendar.json
    fr/event.json
    fr/settings.json
    fr/notifications.json
```

## Détection initiale

1. Préférence persistée (`settings.locale`) si `en` ou `fr`
2. Sinon langue device si `en` ou `fr`
3. Sinon **`en`**

## Règles

- Aucune chaîne UI / a11y / corps de notif app hors catalogues
- Toute nouvelle clé : **EN + FR dans la même PR** (EN obligatoire car fallback)
- Dates : `date-fns` locales `enUS` / `fr` synchronisées avec i18n
- Noms mois/jours des vues : via locale active
- Contenu utilisateur (titre, description, lieu) : **non traduit**

## Settings

Sélecteur langue EN/FR ; persistance immédiate ; re-render catalogues + dates.
