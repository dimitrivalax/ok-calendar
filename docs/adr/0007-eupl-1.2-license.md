# ADR-0007 : Licence EUPL-1.2

- Statut : Acceptées
- Date : 2026-09-14

## Contexte

Le template Expo livrait un LICENSE MIT (copyright Expo). Le projet Ok-Calendar est open source sous licence choisie par les mainteneurs : EUPL-1.2.

## Décision

Remplacer le LICENSE racine par le texte officiel **European Union Public Licence v. 1.2** (EN). Mentionner EUPL-1.2 dans README et CONTRIBUTING.

## Conséquences

- Copyleft / compatibilité EUPL à respecter pour les contributeurs
- SPDX : `EUPL-1.2`

## Alternatives rejetées

- Conserver MIT template Expo — ne reflète pas le choix projet
- GPL-3.0 seule — non retenu par les mainteneurs
